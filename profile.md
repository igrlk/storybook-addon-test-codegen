I'm a Staff Engineer at Clarify, based in London. I build tools that help

## What I'm building

### [UI Verify](https://uiverify.ai)

Visual testing for developers and coding agents. UI Verify captures screenshots
from Storybook, Playwright, or Vitest and compares them against a baseline. AI
review helps distinguish intended changes from regressions, and an MCP server
lets coding agents inspect and review the results.

[Explore UI Verify](https://uiverify.ai) · [Set it up with Storybook](https://uiverify.ai/docs/quickstart-storybook)

### [Storybook Addon Test Codegen](https://github.com/igrlk/storybook-addon-test-codegen)

Interact with your components in Storybook and turn those interactions into test
code. Record clicks and typing, add assertions, and save the generated test back
to your story.

I also use the addon to test UI Verify on a real open-source project, with visual
checks for the addon's own UI in light and dark themes.

[Try the demo](https://igrlk.github.io/storybook-addon-test-codegen/) · [Browse the code](https://github.com/igrlk/storybook-addon-test-codegen)
